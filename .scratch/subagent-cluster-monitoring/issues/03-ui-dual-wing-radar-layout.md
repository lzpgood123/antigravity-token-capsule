# Issue 03: UI 方案 C（旁置双翼 / 集群实时雷达）布局实现

Status: ready-for-agent
Type: task

## Description
在 `capsule_ui.py` 中实现方案 C 的双翼展开布局：
1. 提供双翼模式窗口结构（总宽约 680px）：左翼为主会话完整卡片，右翼为智能体集群实时雷达。
2. 左右并排，右翼展示集群总额大盘、全局总费用（主会话+集群）及所有活跃 Agent 的微型条和吞吐速率。
3. 动态支持在紧凑单卡（320px）与双翼展开（680px）之间平滑调整窗口几何尺寸与可见性。

## Acceptance Criteria
- 切换到双翼模式时窗口几何尺寸自动适应，左右两侧数据同时实时刷新。
- 支持 5 套主题在双翼下的完整渲染与半透明毛玻璃效果。
