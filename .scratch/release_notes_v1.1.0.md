### 🌟 本次更新亮点 (Highlights)

1. **🤖 Subagent 智能体集群监控与多层级树形级联 (Recursive Tree Hierarchy)**：
   * 自动嗅探会话执行轨迹 (`transcript.jsonl`)，毫秒级提取派生子智能体角色名与运行状态。
   * 率先支持 **L1 ➔ L2 ➔ L3 多层级嵌套树形级联展示**（如 Teamwork Lead ➔ Project Orchestrator ➔ Workers）。
   * 节点独立计费 + 派生任务自动级联向上汇总（如 `派生 16 个子任务 (6.78M · $17.701)`）。
   * 手风琴状态智能防抖记忆，轮询重绘不回弹、不抖动，消除历史日志干扰。

2. **📐 混合双布局体系 (Hybrid Dual-Layout Modes)**：
   * **紧凑单卡模式 (Compact Tab, 320px)**：顶部 Tab 丝滑切换「💬 主会话」与「🤖 Subagents · N」，支持多层级任务平滑折叠展开，适合日常专注编码。
   * **旁置双翼模式 (Dual-Wing Radar, 680px)**：左右双屏全景并列，左侧主会话物理卡片，右侧实时集群雷达大盘，底部配备全局联合账单条。
   * **托盘与右键一键热切**：右键菜单支持在「紧凑单卡」与「旁置双翼」之间无缝切换，偏好自动持久化。

3. **💰 财务双计费联动结算 (Dual-Billing Linkage)**：
   * 物理上下文与财务口径解耦：主会话进度条严格反映 256k 物理窗口，卡片底部同步显示 `累计折算费用: $X.XXX (含 Subagents: $Y.YYY)`，彻底扫除多 Agent 预算盲区。

4. **🚀 3 种分发模式任选 (3 Distribution Packages)**：
   * 👑 **Windows 安装包（推荐日常使用）**：基于 Inno Setup 构建，免管理员权限直接安装，自动生成桌面图标，安装后启动即享**毫秒级秒开（0.2s）**体验！
   * 📦 **绿色便携 ZIP 包**：解压即用，包含完整依赖，同样享受毫秒级秒开！
   * 📄 **单文件独立版 EXE**：单个文件拷走即用，无需安装任何环境。
